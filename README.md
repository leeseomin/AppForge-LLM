# AppForge-LLM

한 줄의 요청으로 앱을 만들고, 검증·미리보기한 뒤 소스 ZIP으로 내려받는 로컬 AI 앱 빌더입니다.

## 실행

Python 3.11+, Node.js/npm, Bun, LLM API 키가 필요합니다.

Windows 11에서는 `build.bat`을 더블클릭하세요.

macOS/Linux에서는 다음 명령을 실행하세요.

```bash
./build.sh
```

브라우저가 열리면 LLM을 연결하고 만들 앱을 입력하세요.

자세한 내용은 [한국어 문서](README.ko.md)를 참고하세요.
